#  Data Science Portfolio: 100 Days of Code (Days 72-80)

A dedicated repository tracking the Data Science and Machine Learning modules from the *100 Days of Code* Python bootcamp. This section focuses heavily on exploratory data analysis (EDA), data visualization, and statistical computation using industry-standard Python libraries.

##  Objective
To master data manipulation and build a strong foundation in statistical analysis and visualization, transitioning from raw datasets to actionable business insights and predictive models.

##  Tech Stack & Libraries
* **Data Manipulation:** Pandas, NumPy
* **Data Visualization:** Matplotlib, Seaborn, Plotly
* **Machine Learning:** Scikit-Learn (Linear & Multivariable Regression)
* **Environment:** Jupyter Notebooks / Google Colab

##  Curriculum & Project Breakdown
This repository contains standalone Jupyter Notebooks for each daily project, demonstrating progressive skill development with different datasets:

* **Day 72:** Data Visualisation with Matplotlib *(Analyzing Programming Languages)*
* **Day 73:** Aggregate & Merge Data with Pandas *(Analyzing the LEGO Dataset)*
* **Day 74:** Resampling and Visualising Time Series *(Google Trends Data)*
* **Day 75:** Beautiful Plotly Charts *(Analyzing the Android App Store)*
* **Day 76:** Computation with NumPy and N-Dimensional Arrays
* **Day 77:** Linear Regression and Data Visualisation with Seaborn *(Movie Budgets vs. Revenue)*
* **Day 78:** Advanced Visualization with Plotly, Matplotlib & Seaborn *(Analyzing the Nobel Prize)*
* **Day 79:** Statistical Analysis with t-Tests & Distributions *(The Tragic Discovery of Handwashing)*
* **Day 80:** Capstone Project - Predicting House Prices *(Multivariable Regression)*

##  Key Takeaways
Throughout these modules, I have moved beyond basic scripting to actual data engineering workflows. I am now comfortable taking messy `.csv` files, cleaning missing values (`.dropna()`), merging dataframes, and rendering interactive, multi-layered charts to find hidden trends.
